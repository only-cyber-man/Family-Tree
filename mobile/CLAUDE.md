# mobile/: conventions

Expo SDK 57 / RN 0.86 (New Architecture), expo-router with typed routes, yarn with its own `yarn.lock`. Package versions come from `npx expo install`; do not hand-bump the native ones.

- **Done bar:** `yarn typecheck`, `yarn test`, and `yarn bundle:android` + `yarn bundle:ios` all pass.
- **Backend:** `src/lib/api.ts` is the only file that talks to PocketBase. It mirrors the web client (`../src/lib/hooks/useTree.tsx`, `../src/app/**`) exactly: same collections, fields, filters (`tree.id = …`) and `expand: "relationshipName"`. Never invent fields or collections. Anything the design marks as a proposal (meNode, nickname, notes) is either device-local (`src/store/settings.ts`) or left out.
- **Pure logic** goes in `src/lib/`, with no React or Expo imports (tokens are OK) and a jest test in `src/lib/__tests__/`. This covers layout, LOD, camera math, edges, relationship path and kinship, upcoming dates and reminder planning, filters, search, and .ics.
- **Writes are online only** (no offline write queue). A failed save keeps the form open with a `SaveFailed` "Try again". While offline, write controls are disabled next to an `OfflineWriteHint`. Creates take client ids (`src/lib/ids.ts`) and go through `createOnce` (`src/lib/idempotent.ts`). Every write names its tree id.
- **Sign-out / account switch:** `wipeAccountData()` bumps the epoch (`src/store/epoch.ts`). Async store work captures `epochGuard()` and checks it before every write.
- **House ads:** `src/services/ads.ts` is the only file that talks to ads.cyber-man.pl (signed requests, feed cache, impressions); the pure parts (path, signing message, parsing, weighted pick, audience headers) are in `src/lib/ads.ts` with tests. Render a slot with `<AdBanner placement="…" />`; it shows nothing offline or without an ad. Every request also carries the unsigned audience headers (`X-App-Version`, `X-OS`, `X-Device`, `X-Locale`) that feed the dashboard's Audience section; never add identifiers to them, and keep the privacy policy (`../src/app/privacy/content.tsx`) in step with what is sent.
- **Side effects** (notifications, haptics, image picker, sharing) go in `src/services/`. **State** is zustand in `src/store/`. The active tree is `useTree`; derived data comes through the hooks in `src/hooks/useTreeData.ts`.
- **Theme:** never hard-code colours. Use `useTheme()` (`t.c.*`, `t.node.*`, `t.shadow()`). `src/theme/tokens.ts` is generated by `scripts/gen-tokens.js` and must not be edited by hand. Text goes through `src/components/Text.tsx`, which maps weights to font families.
- **Dates** are calendar labels (`CalendarDate`, year/month/day; `src/lib/dates.ts`) and can be any day from year 1, because trees reach centuries back. Never build them with `new Date(y, m, d)` (two-digit years become 19xx); use `toJsDate` and friends. `DateField` is the only date picker. Android's dialog labels days before 15 Oct 1582 in the Julian calendar, so it goes through `src/lib/julian.ts`.
- **Read-only viewers:** remove edit controls; don't disable them. Ownership is `tree.creator === user.id` (`useIsOwner()`).
- **Sheets:** use `RouteSheet` (a transparentModal route plus @gorhom/bottom-sheet). Snap points come from `tokens.mobile.sheetSnapPoints`.
- **Canvas** (`src/canvas/TreeCanvas.tsx`): gestures move a native transform on the UI thread. When a gesture ends, the camera is committed and the SVG is redrawn in screen space at that camera. That redraw is also when LOD is decided. Nodes have fixed on-screen sizes per LOD.
- Commit only when asked. Keep `android/`, `ios/`, `.expo/` out of git.
- **Strings:** never hard-code user-visible text. Use `const T = useT()` in components and `getT()` elsewhere. Pure lib functions take the dictionary as their last parameter, defaulting to `en`. Add every key to `src/i18n/en.ts` and to every other dictionary (`pl.ts`, `es.ts`, `fr.ts`, `de.ts`, `pt.ts`, `af.ts`, `hi.ts`); each is typed as `Dict`, so the compiler enforces that they are complete. Languages are listed once, in `src/i18n/index.ts`.
- **Tablets:** layout comes from `useLayout()` (window width: ≥ 600 dp tablet, ≥ 900 dp wide), with the pure rules in `src/lib/responsive.ts`. Tablets get a left nav rail instead of the bottom tab bar. Tablet sheets are centred cards (forms) or right drawers (person, filters) via `RouteSheet`'s `tablet` prop. Wide windows use master–detail (Home, Dates) and a persistent person panel on the Tree tab. Everything else is capped with `Screen maxWidth` (FORM_MAX / READING_MAX / LIST_MAX). Phones are locked to portrait at runtime; tablets rotate.
