Mobile app · iOS and Android

Built around four jobs: place a face fast, know whose day is coming, add someone on the spot, browse the tree at phone size. Five tabs, Add in the middle. Screens use the same tokens as the web (see Brand); dark mode is the same layout with the dark token set. Interaction specs, component inventory and store frames are in the hand-off.
